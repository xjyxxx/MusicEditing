# S01 — 开班：本地 AI 音视频工具怎么做成「能卖的产品」

**时长**：90–120 分钟 · **模块**：A 地基

## 本期目标

学员能讲清：本仓库解决什么问题、为什么 C++/Python 分层、文档真源在哪、课程 12 期怎么走。

## 幻灯逻辑（与 PPT 同步）

1. 痛点：云剪辑 / 隐私 / 平台水印 / 批量无人值守  
2. 产品边界：纯本地、可卖、非 NLE 时间线重构  
3. 功能全景：核心 / 工作流 / 趣味 / 帮助  
4. 架构一句话：UI(MVVM) → Bridge → CLI/Player → media_engine  
5. 文档纪律：design 真源 · LEARNING 自学 · archive 非教材  
6. 12 期路线图与期末标准  
7. Lab：菜单→用户价值图  

## 讲师口播要点

- 强调「能打包给别人电脑跑」比「演示 Demo」难一个数量级。  
- 对照根目录产品交互稿：只读需求；冲突以 `docs/design` 为准。  
- 预告 S11–S12：试用门禁、更新通道、签名与收银台是商业课不是附录。

画出：首页 / 切片 / 增强 / 去水印 / 队列 / 个人中心 → 各解决谁的什么痛点。
