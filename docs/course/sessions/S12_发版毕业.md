# S12 — 发版毕业课：打包 · 更新 · 签名 · 验收

**时长**：90–120 分钟 · **模块**：D 商业发版

## 本期目标

打出 slim 包并 accept PASS；写出上线检查表；能背「四件自备项」。

## 硬核点

- profile：slim / standard / full；默认 .pyc + embed runtime  
- `accept_portable`；Inno Setup；`release_oneclick`  
- 更新 / OTA：`publish_update_manifest` + 客户端「下载并升级」；**上线需 CDN + 正式 `update_manifest_url`**；**禁止发版包留 127.0.0.1**  
- 签名：`pack --sign` + `build_installer` 后签 Setup（无证书跳过属正常）  
- 自备：干净机、CDN、代码签名证书、外部收银台（支付成功调 `POST /v1/issue`）  

## Lab（毕业）

1. `python scripts\pack_portable.py --profile slim --zip`  
2. `python scripts\accept_portable.py` → PASS（看签名状态打印）  
3. `publish_update_manifest.py` 生成 dist/update  
4. 填写一页「上线检查表」（含自备项 + OTA CDN URL）
