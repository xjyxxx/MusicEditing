# S02 — 仓库手术刀：从 clone 到 run_ui_x64

**时长**：90–120 分钟 · **模块**：A 地基

## 本期目标

独立完成 x64 构建与 UI 启动；说清产物目录；能排查缺 FFmpeg / 缺 VS / 缺 pip 依赖。

## 硬核命令链

```bat
scripts\setup_ffmpeg_x64.bat
build_x64.bat
pip install -r client\scripts\requirements.txt
run_ui_x64.bat
```

## 必须讲清

- `build_x64\bin\Release\`：`media_cli.exe` / `media_player.exe` / `media_engine.dll`  
- Win32 vs x64 双预设互不覆盖  
- OpenCV / ORT / 模型均为可选；缺模型 UI 提示而非必崩  
- 配置：`client/resources/config/app.conf`
